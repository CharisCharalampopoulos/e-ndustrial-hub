# e-ndustrial-hub

Εφαρμογή για κινητά για την αναζήτηση υπηρεσιών συντήρησης βιομηχανικού
εξοπλισμού και τη δοκιμαστική υποβολή αιτημάτων τεχνικής υποστήριξης.

[Άνοιγμα εφαρμογής](https://charischaralampopoulos.github.io/e-ndustrial-hub/)

## Υλοποίηση

Η εφαρμογή σχεδιάστηκε στο Figma και υλοποιήθηκε με HTML, CSS και JavaScript.
Ο χάρτης χρησιμοποιεί Leaflet και δεδομένα OpenStreetMap. Η υποβολή
αιτήματος είναι προσομοίωση.
